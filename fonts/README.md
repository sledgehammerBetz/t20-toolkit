# Fontes do T20 Toolkit

- **Inter** (interface) — `inter-*.woff2`, reduzidas ao alfabeto latino. SIL OFL 1.1, © The Inter Project Authors.
- **Lora Bold** (títulos) — `Lora-Bold.woff2`, o arquivo original só convertido para WOFF2 (mesmas formas, sem alteração). SIL OFL 1.1 (`LORA-OFL.txt`), © The Lora Project Authors.

O Figma pede Merriweather nos títulos. Se a Merriweather estiver instalada no computador, ela é usada; senão, a Lora.
